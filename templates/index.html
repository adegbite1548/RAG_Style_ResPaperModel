About the Project

This system uses retrieval-augmented generation to search through a large collection of research papers and get papers that are most relevant to your query.

The database this uses was created from scratch and is mainly comprised of papers relating to artificial intelligence. So you can find papers linked to fields like robotics, computer vision e.t.c. As time goes on more will be added to the database.
